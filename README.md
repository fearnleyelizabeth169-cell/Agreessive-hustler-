# Global Timezone Clock

A real-time digital clock that displays the current time across 12+ different timezones worldwide.

## Features

✨ **Real-Time Updates** - Updates every second with smooth animations
🌍 **Multiple Timezones** - Display 12 major world timezones simultaneously
⏰ **24H/12H Format** - Toggle between military time and AM/PM format
🎨 **Dark Modern UI** - Sleek design with cyan and neon accents
📱 **Fully Responsive** - Works perfectly on desktop, tablet, and mobile
⚙️ **Interactive Controls** - Add custom timezones, reset to defaults

## Included Timezones

## How to Use

1. **View the Clock** - Open `timezone-clock.html` in your browser
2. **Toggle Format** - Click "Toggle 24H/12H Format" to switch time display
3. **Add Timezones** - Click "Add Timezone" to add new timezones
4. **Reset** - Click "Reset to Default" to restore original timezones

## Features Breakdown

- **Live Clock Display**: Each timezone shows current time, date, and UTC offset
- **Auto-Update**: Clock updates automatically every second
- **Smooth Animations**: Staggered card animations and smooth transitions
- **Responsive Design**: Adapts to all screen sizes
- **Color-Coded**: Cyan for primary information, neon pink for accents

## Technical Details

Built with:
- Pure HTML5
- CSS3 (Flexbox, Grid, Animations)
- Vanilla JavaScript (No dependencies)

Timezone handling uses the Intl API for accurate timezone conversions across all regions.
